Token TIL-0000-0000-00 doesn't match any active report

This can happen for a few reasons:

  • Typo in the token — check it against the report; tokens look like TIL-XXXX-XXXX-XX.
  • The token was revoked — students or institutions can withdraw a shared report at any time.
  • The report isn't genuine — a document carrying a token that doesn't verify should not be trusted.
If you believe this is an error, ask the report holder to re-share their verification token, or contact their institution directly.
